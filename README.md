# Stock Volatility Prediction Using Machine Learning

## Project Overview

This project focuses on predicting stock market volatility using Python and machine learning techniques. It combines historical stock prices with macroeconomic indicators to study how market conditions affect volatility.

The project involves data cleaning, exploratory data analysis, feature engineering, model development and performance evaluation.

## Project Objectives

- Analyse historical stock market trends and volatility.
- Explore the relationship between market data and economic indicators.
- Develop machine learning models for volatility prediction.
- Compare model performance using standard regression metrics.

## Technologies Used

- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook / Google Colab
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- **Data Sources:** Historical stock market data and Federal Reserve Economic Data (FRED)

## Machine Learning Models

- Ridge Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Model Evaluation

The models are evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Conclusion

This project demonstrates how machine learning can be applied to financial time-series data to analyse volatility patterns and compare different prediction approaches.

The work provides a foundation for further development in financial forecasting and risk analysis.
